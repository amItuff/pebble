# Pebble Help

Print this, unchanged, and nothing else:

```
PEBBLE  short, honest replies

Modes     /pebble brief   one sentence
          /pebble plain   up to 3 sentences (default)
          /pebble full    normal length, no filler
          /pebble off     stop

Commands  /pebble-intent    restate the real question + assumptions, then answer
          /pebble-verify    tag claims [sure] [guess] [unchecked]
          /pebble-audit     find token waste in this chat (estimates)
          /pebble-handoff   compress this chat into a note for a new chat
          /pebble-rewrite   tighten your prompt before you send it
          /pebble-lint      score a SKILL.md
          /pebble-gain      show measured benchmark results
          /pebble-help      this screen

Never cut  code, commands, numbers, and the ⚠ risk line.
Say "explain" or "in detail" for one full-length reply.
```
